# Asset Licenses

Track every imported asset and attribution requirement before release.

## Required Fields
- Source URL
- Author
- License
- Attribution required (Y/N)
- Notes (file path in repo)

## Verification Steps
1. Save the original license text or screenshot when downloading a pack.
2. Copy required attribution text into this file immediately.
3. Block release if any shipped asset has unknown license status.
